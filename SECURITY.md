# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Do not open a public GitHub issue.**
2. Send an email to the maintainer at `olof.hellqvist@gmail.com` with the details.
3. Include steps to reproduce the vulnerability, affected components, and any relevant logs or environment details.

You should receive an acknowledgment within 48 hours. Validated vulnerabilities will be resolved promptly in a patch release.
